# Observability and Data Quality

Data quality is part of the digital twin.

## Every Signal
Track:
- source
- timestamp
- freshness
- validity
- confidence
- measured/inferred status

## Station Observability
Example:
Station 21
Telemetry coverage: 38%
Measured: cycle time, motor state
Inferred: equipment health
Manual: torque inspection
Unknown: vibration

## Data States
MEASURED · INFERRED · PREDICTED · SIMULATED · UNKNOWN

## Missing Data
Never silently turn missing data into zero.

## UI
Make weak instrumentation visible so users understand when predictions rely on limited evidence.
