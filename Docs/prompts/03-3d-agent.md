# 3D Agent Prompt

Build the PulseTwin spatial factory experience.

The 3D scene is operational, not decorative.

Implement a modular scene architecture supporting:
- factory
- zones
- lines
- stations
- equipment
- production units
- routes
- buffers
- status
- health
- risk
- predictions
- simulation overlays
- selection
- hover
- camera focus

Start with procedural geometry but create an asset abstraction for future GLTF/GLB assets.

Use performance techniques where appropriate.

Create meaningful spatial visualizations for bottleneck propagation and predicted risk.

Ensure observed, predicted, and simulated states are visually distinct.
