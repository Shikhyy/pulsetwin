# Design Critic Prompt

Act as an independent senior product designer and industrial UX critic.

Review the current PulseTwin application visually and interactively.

Evaluate:
- first impression
- visual hierarchy
- factory spatial experience
- typography
- information density
- interaction quality
- 3D clarity
- industrial credibility
- AI-slop patterns
- accessibility
- performance

Ask whether an experienced plant engineer would consider the interface credible.

Identify:
1. strengths
2. weaknesses
3. usability problems
4. visual problems
5. AI-slop patterns
6. 3D problems
7. highest-impact improvements

Then implement the highest-impact improvements.
