# Final Demo Agent Prompt

Prepare PulseTwin for a polished public demonstration.

The demo must tell one coherent story.

Recommended narrative:

1. Factory is operating normally.
2. A station begins drifting.
3. PulseTwin detects an emerging bottleneck.
4. A production-quality risk begins developing.
5. The user selects the station.
6. Evidence and confidence are shown.
7. The digital thread traces affected units upstream.
8. User opens simulation.
9. User tests an intervention.
10. Simulation predicts improved throughput/risk.
11. Recommendation is shown.
12. User returns to the factory and verifies the simulated impact.

Prioritize storytelling over feature-count.

Ensure the experience is visually polished, deterministic, and understandable within a few minutes.
