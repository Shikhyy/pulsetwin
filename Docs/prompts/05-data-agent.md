# Data Agent Prompt

Build a realistic synthetic production data system for PulseTwin.

Generate:
- 30–50 stations
- multiple production units
- variable cycle times
- queues
- downtime
- equipment degradation
- torque
- vibration
- temperature
- operator variation
- part quality
- environmental variables
- defects
- bottlenecks
- missing sensor data
- manual observations
- delayed quality outcomes

Maintain hidden ground truth for injected events.

Make generation reproducible with a seed.

Provide data suitable for both frontend demonstration and ML evaluation.
