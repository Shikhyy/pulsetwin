# Definition of Done

PulseTwin prototype is complete when a new user can:

1. Open PulseTwin.
2. See a realistic 3D factory.
3. Observe production units moving through the line.
4. See station conditions.
5. Notice an emerging bottleneck.
6. Select the affected station.
7. Inspect telemetry.
8. See a prediction and confidence.
9. Understand supporting evidence.
10. Trace affected vehicles.
11. Discover a possible upstream contributor.
12. Open simulation.
13. Create an intervention.
14. Run the scenario.
15. Compare baseline and scenario.
16. See projected operational impact.
17. Receive a recommendation.
18. Understand its confidence.
19. Return to the operational view.

The experience must feel like one coherent product.
