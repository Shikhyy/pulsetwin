# Testing and Validation

## Software Tests
- unit tests
- integration tests
- API tests
- simulation tests
- prediction tests
- UI tests
- end-to-end tests

## Twin Validation
Verify state transitions, event ordering, timestamps, and identity consistency.

## Prediction Validation
Use held-out synthetic periods and later quality outcomes. Track false positives and false negatives.

## Simulation Validation
Compare simulator behavior against known scenarios and conservation/flow expectations.

## Demo Reliability
Core demo scenarios should be deterministic enough to reproduce.
