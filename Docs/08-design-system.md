# Design System

## Objective
PulseTwin should look like a credible industrial technology product for operators, engineers, managers, and leadership.

## Avoid
- excessive gradients
- purple/blue AI aesthetics
- generic dashboard cards
- excessive rounded containers
- glassmorphism everywhere
- decorative AI effects
- giant hero sections
- chatbot-first interfaces
- meaningless animations
- excessive shadows and pills

## Visual Character
PRECISION · CLARITY · DEPTH · CONTROL · SIGNAL · MOTION

## Layout
Prefer strong grids, asymmetric information layouts, a large spatial viewport, compact contextual panels, dense but readable information, and edge-aligned controls.

## Information Hierarchy
The interface should quickly answer:
1. Where is the problem?
2. How serious is it?
3. What is affected?
4. Why might it be happening?
5. What happens next?
6. What can I do?

## Semantic States
Normal, Attention, Warning, Critical, Predicted, Simulated, Unknown.

Use non-color indicators too.

## Motion
Animation should communicate production flow, state changes, emerging risk, temporal prediction, or simulation.

## Signature Interaction: The Pulse
When an anomaly emerges:
1. affected station becomes emphasized;
2. a signal propagates through affected flow;
3. contextual information appears;
4. predicted downstream impact becomes visible;
5. user can enter investigation mode.

This should become a recognizable PulseTwin interaction.
