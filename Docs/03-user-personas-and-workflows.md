# User Personas and Workflows

## Floor Supervisor
Needs immediate awareness of station state, emerging issues, affected production units, and safe next actions.

Primary workflow:
Observe → select station → inspect evidence → act or escalate → verify.

## Plant Manager
Needs trends, bottleneck patterns, quality performance, capacity implications, and what-if analysis.

Primary workflow:
Review trends → identify recurring constraint → simulate interventions → compare impact → plan.

## Leadership
Needs business impact, rollout opportunity, investment requirements, confidence, and site-level comparisons.

Primary workflow:
Review opportunity → understand evidence → estimate ROI → prioritize rollout.

## Maintenance Engineer
Needs equipment health, anomalies, degradation patterns, and maintenance context.

## Quality Engineer
Needs defect prediction, traceability, upstream evidence, and validation metrics.

## Core End-to-End Workflow
1. Emerging bottleneck appears.
2. PulseTwin highlights affected station spatially.
3. User inspects current telemetry.
4. Prediction displays probability and horizon.
5. Evidence panel identifies contributing signals.
6. User traces affected vehicles upstream.
7. User opens simulation.
8. User changes a controllable parameter.
9. Simulation estimates downstream effects.
10. User compares baseline vs scenario.
11. System provides recommendation.
12. Outcome is verified against later production data.
