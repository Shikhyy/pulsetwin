# Event and Digital Thread

## Purpose
Connect production history across the factory.

## Core Entity
Production Unit, such as a vehicle body.

## Journey
Vehicle → Station 01 → Station 02 → … → Final Inspection.

## Events
- station entry
- station exit
- cycle completion
- downtime
- alarm
- manual inspection
- quality failure
- sensor anomaly
- operator observation
- maintenance
- material change

## Traceability
A quality event must allow backward navigation through the production journey.

## Root Cause
Rank contributors as hypotheses rather than claiming automatic causality.
